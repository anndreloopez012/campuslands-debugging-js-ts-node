# README — Ejercicio 009: Autos hiperdeportivos

## Cambios realizados

El ejercicio trata sobre **autos hiperdeportivos** y tiene como objetivo **convertir unidades de velocidad correctamente**.

El código original utilizaba funciones relacionadas con puntos y rankings:

- `calcularResultado()`
- `ordenarRanking()`

Estas funciones no correspondían con el objetivo del ejercicio.

Por eso, se modificaron los nombres y la funcionalidad para trabajar específicamente con conversiones de velocidad.
